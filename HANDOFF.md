## Реализовано и нельзя потерять

Все dist/, тесты, документы, pet schema=1 внутри world schema=2, storage key=hamster-life-v1, поведение потребностей, 2 режима и защита детского режима. Экспорт/импорт, блокировка перезаписи повреждённого сохранения. Честное сообщение ограничений времени. Offline shell без внешних ресурсов. В документах обозначены все незавершённые возможности. В 0.2.0 сохранять bond, cage.nest/stash и pet.carry; не терять миграцию старых JSON, перенос без создания еды, паузу между контактами и отсутствие штрафа доверия за отсутствие ребёнка. В 0.2.1 нельзя терять illness, постепенные риски/восстановление, объяснение причины и миграцию отсутствующего illness. Ни одна игровая болезнь не должна обходить детскую защиту. В 0.3.0 сохранить layout.js в offline-кэше, транзакционный черновик без автозаписи, отмену, координаты касания с letterbox, проверку геометрии/мостика и сброс устаревшей цели AI после применения. В 0.3.1 нельзя заменить world одним active.state: это потеряет другие жилища. Сохранить атомарный контейнер v2, перенос одиночного JSON, отдельные подтверждения импорта, окрасы и независимость объектов. При повреждении мира не пропускать молча сломанные клетки.

## Продолжить

1. Прочитать все документы, проверить актуальный GitHub, последние коммиты и PR. Новых незаписанных наработок Astra не предполагать.
2. Прочитать актуальную ветку feature/separate-homes-v0.3.1, коммиты и PR перед любыми изменениями. Пользователь уже создал репозиторий — повторно создавать не нужно.
3. Следовать текущему PR либо создать согласованную ветку от последнего main; выполнить тесты, обновить документы и HANDOFF. В одни и те же файлы одновременно не писать.
4. Пользователю проверить игру на устройстве по TESTING.md. Исправлять замечания в той же истории. Пользователь попросил продолжить разработку; 0.2.0 добавлена по этому запросу. Следующий шаг — проверить новые функции на устройстве. Новую версию 0.3.1 не считать проверенной на планшете до подтверждения пользователя.
5. Публикация GitHub Pages из dist допустима после проверки лимитов/настроек. Никаких платных действий. APK — только после проверки браузерной версии.

## Запуск

Для пользователя — URL в Chrome; первая загрузка с сетью, далее офлайн после кэширования (ещё не проверено на устройстве). Разработчику — `python3 -m http.server 8000 --directory dist`, localhost:8000; тесты `npm test`. Без npm install.

## Известные проблемы

См. TESTING.md. Главные незавершённости: ручная приёмка Android, биологические виды, архив завершённых историй и APK. Коэффициенты возраста и здоровья условны. Предельный офлайн-интервал 30 дней. Смена часов не защищена доверенным сервером.
