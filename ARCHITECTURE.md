# Архитектура 0.1.0

## Модули

| Модуль | Файл | Ответственность |
|---|---|---|
| SimulationEngine | dist/js/model.js | Пошаговый расчёт состояния и возвращения |
| HamsterAI | dist/js/model.js | Приоритетный автомат потребностей, цели движения |
| NeedsSystem | dist/js/model.js | Голод, жажда, энергия, стресс, здоровье |
| CageSystem | dist/js/model.js | Запасы, чистота, расположение предметов |
| InteractionSystem | dist/js/model.js | Кормить, вода, уборка, тихое общение |
| TimeSystem | dist/js/model.js | Безопасный интервал, предупреждения часов |
| EventJournal | dist/js/model.js | Последние 100 событий |
| SaveManager | dist/js/save.js | Проверка схемы, локальное чтение/запись |
| Renderer | dist/js/renderer.js | Canvas, процедурная графика без внешних ресурсов |
| UI | dist/js/app.js | Кнопки, панели, настройки, экспорт/импорт, жизненный цикл |
| Offline shell | dist/sw.js | Кэш локальных ресурсов |

Логические классы выделены независимо и не зависят от DOM. Для прототипа они объединены в один файл model.js; при росте разделять, сохраняя публичные интерфейсы.

## Состояние

JSON schema version=1: lastSeen (Unix ms), mode (child/realistic), age/elapsed (секунды), alive, deathReason, needs, cage, pet, journal, seed. Потребности в 0..100; hunger и thirst возрастают от нехватки, UI инвертирует их как сытость и воду. Food/water — условные запасы. AI сам расходует их, кнопки только пополняют.

AI выбирает воду, еду, домик по порогам, затем активность в зависимости от энергии. Случайность с сохранённым seed применяется только к свободной активности. Рисунок хомяка интерполируется к позиции модели. Ограничение отрисовки около 30 FPS, UI обновляется дважды в секунду.

## Время

Онлайн шаг <=0.5 с. Офлайн шаг <=30 с, максимум 30 дней за одно возвращение. Потребности рассчитываются до поведения. Это приближение, поэтому онлайн/офлайн не обязаны давать побитово одинаковый результат. Переход в фон сохраняет состояние, возврат пересчитывает интервал. Длинная пауза rAF тоже вызывает resume. Дневник и возраст используют время модели. После пересчёта lastSeen устанавливается в текущее время устройства.

Отрицательный интервал принимается равным нулю. Скачок >30 дней ограничивается и объясняется в дневнике. Защиты от намеренной смены часов нет: внешнего доверенного времени не используется. Фоновый процесс и сервер отсутствуют.

## Режимы

Child: здоровье >=25% всегда, включая отсутствие. Дефициты и стресс сохраняются, вода и еда не пополняются автоматически. Realistic: длительные критические дефициты или грязь снижают здоровье, возраст >90 дней — условное старение. Возможна смерть. Смерть сохраняется, не отменяется сменой режима. Тело прикрыто спокойным экраном памяти, дневник доступен. Отдельных болезней нет.

## Сохранение

localStorage key hamster-life-v1, автосохранение каждые 5 с, после действий, на visibilitychange/pagehide. Последние секунды могут потеряться при принудительном завершении. Не гарантия долговечности данных браузера. Повреждённая запись не перезаписывается: автозапись блокируется до явного импорта валидного файла. Экспорт скачивает текущий JSON, импорт проверяет схему и требует подтверждения замены. Недоступность storage сообщается в UI.

## Обновления и APK

Менять имя кэша при обновлении shell. Не менять key/version сохранений без миграции. APK — будущая отдельная оболочка с локальными assets, без сервера. Не подключать Android API, платные SDK или облачную симуляцию. Конкретный способ сборки и подписи APK ещё не выбран и не проверен.
