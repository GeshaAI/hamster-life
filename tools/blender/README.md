# Blender hamster prototype v0.1
Generate a basic golden-and-white Syrian hamster using Blender and export to GLB for Godot 4.
Workflow: Actions > Build hamster GLB > Run workflow (select feature branch) > download hamster-model artifact.
Files: hamster.glb (Godot import) and hamster.blend (editable Blender project).
Status: geometry only; no armature, animations, fur cards, or performance validation yet.
Costs: uses GitHub-hosted runner minutes subject to plan limits; no paid service is intentionally required.
Do not claim successful build until Actions is green.
