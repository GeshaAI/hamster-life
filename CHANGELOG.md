# Изменения

## 0.1.1 — 2026-10-19

Компактная горизонтальная раскладка для планшета: клетка слева, кнопки 2×2 и показатели справа; высота учитывает доступный viewport. Canvas целиком вписывается без обрезки. На малых экранах сохранена прокрутка, в боковой панели есть страховочная прокрутка при увеличенном шрифте. Кэш обновлён до 0.1.1, схема и ключ сохранений прежние. Пользователь подтвердил работу 0.1.0 на планшете; 0.1.1 требует проверки раскладки на устройстве.

## 0.1.0 — 2026-10-19

Первый реализованный прототип. Приоритетный AI с движением к кормушке, поилке, домику и колесу. Голод, жажда, энергия, здоровье, стресс, расход ресурсов и чистоты. Два режима с бережным экраном смерти. Canvas-клетка с процедурным хомяком, русские панели и крупные действия. LocalStorage, проверка повреждений, расчёт отсутствия, резервные копии. Service Worker и manifest. Документация передачи и тесты.

Проверки на реальном Android ещё не проведены. Репозиторий GeshaAI/hamster-life создан пользователем; 19.10.2026 доступ push/admin подтверждён. Исходники подготовлены отдельной веткой feature/v0.1-prototype с Pull Request в main. Актуальные ссылки — в HANDOFF.md. APK не готов, GitHub Pages не включён.
