`node --check` для JS-модулей и Service Worker. Браузерные проверки не выполнены: доступный Sites workflow не предоставил control-browser; по правилам среды альтернативный браузер не запускался. Моделирование Service Worker в Node не доказывает установку PWA и реальный офлайн-запуск на Android.

## Ручная проверка жилищ 0.3.1 — ОЖИДАЕТСЯ

- После обновления в первом домике должны сохраниться Пончик, ресурсы, возраст, доверие и планировка.
- «Домики» → создать второго питомца, выбрать имя, окрас и характер. Проверить новый внешний вид и переключение обратно без сброса.
- Покормить одного питомца: запасы другого не меняются от этого действия. После возвращения время может естественно изменить потребности.
- Перезагрузить: оба питомца и выбранный домик восстанавливаются. Проверить редактор отдельно в каждой клетке.
- Экспорт всех жилищ → импорт, отмена общей замены. Отдельный старый JSON заменяет только текущую жизнь.
- Длинные имена и поля создания должны быть удобны на планшете/телефоне. Проверить шапку «Домики» и цвет трёх окрасов.

## Ограничения

- Рисованная Canvas-сцена, без 3D-движка; качество и FPS на устройстве ещё не измерены.
- Перемещение предметов только по горизонтали. Деревянный мостик неподвижен. Геометрия упрощённая; хомяк не моделирует физическое огибание мебели. Сон изображён укрытием в домике и z.
- Игровое недомогание обобщённое, не модель конкретных инфекций или ветеринарного диагноза. Пороги и скорость выздоровления — условные.
- Офлайн шаг 30 с приближённый. Ограничение расчёта 30 дней, не защита от манипуляций часами.
- localStorage может быть очищен браузером; резервная копия — ответственность явного экспорта.
- При порче исходного сохранения автозапись блокируется, чтобы не уничтожить запись; нужен импорт валидного файла.
- Установка на главный экран зависит от браузера и политики доступа к частному адресу. Нет гарантии PWA в WebView ChatGPT.
- Лимит 3 жилища, включая завершённые жизни. Архива/удаления нет. Окрас косметический, не биологический вид.
- Нет APK. GitHub PR со статусом передачи указан в HANDOFF.md. Ссылка публикации сама по себе не подтверждает Android-приёмку.
