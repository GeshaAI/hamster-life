# HAMSTER LIFE — Живой мир

Рабочий прототип 0.3.3 браузерного симулятора заботы о Пончике. Полностью русский интерфейс, Canvas 2D с иллюстративным объёмом, без внешних библиотек, аналитики, рекламы и сетевых API.

Открыть: https://hamster-life.halejam.chatgpt.site (личный доступ владельца; состояние публикации см. HANDOFF).

## На Android без компьютера

1. Откройте адрес в Chrome под аккаунтом владельца. Если встроенный браузер мешает, скопируйте адрес в Chrome.
2. Дождитесь уведомления «Офлайн-версия сохранена». Первая загрузка требует сети и доступа к адресу.
3. Через меню Chrome добавьте на главный экран, если браузер предлагает эту возможность.
4. Наполните кормушку или поилку. Само нажатие не меняет голод: хомяк должен дойти до предмета и поесть/попить.
5. В настройках скачайте резервную копию сохранения. При очистке данных браузера локальный прогресс удаляется.
6. Проверьте запуск с выключенной сетью. Если браузер или авторизация мешает запуску, сообщите точный экран. Реальный офлайн-запуск на Android ещё не проверен.

На планшете горизонтально (ширина от 700 CSS px, высота от 480 CSS px) включается компактный экран: клетка и уход рядом. При крупном шрифте боковая панель прокручивается; портретный экран сохраняет обычную прокрутку.

## Поиграть с питомцем

«Общаться» → «Тихо поговорить» сохраняет прежнее взаимодействие. «Поиграть с мячиком» предлагает короткую 30-секундную активность без очков: касанием подстилки/движением пальца перемещается игрушка, хомяк сам подходит. Если питомец спит, голоден, хочет пить, болен или устал, интерфейс объясняет, почему сейчас нужен другой уход. При ухудшении состояния активность заканчивается. Между играми есть пауза; игрушка и её время сохраняются отдельно у каждого питомца. Пока мячик в клетке, перестановка мебели недоступна; закончить игру можно через «Общаться».

## Жилища и питомцы

Кнопка «Домики» вверху открывает до трёх независимых клеток. Новому питомцу выбираются имя, один из трёх окрасов и характер; он начинает в детском режиме. Окрас — визуальный вариант, не биологический вид. У каждого свои потребности, ресурсы, возраст, режим заботы, доверие, гнездо, планировка и дневник. Невыбранные жилища рассчитываются при переключении, открытии списка, экспорте и возвращении в игру. Фоновый процесс не нужен.

Старое одиночное сохранение автоматически становится первым домиком. В настройках можно поменять имя, скачать все жилища или только текущего питомца. Импорт мира заменяет все жилища с подтверждением; импорт одиночного JSON заменяет только текущую жизнь, сохраняя остальных. Истории умерших питомцев тоже занимают слот; удаления и архива пока нет.

## Что реализовано

Автономные поиск корма и воды, движение, потребление запасов, сон в домике, колесо, умывание, исследование, укрытие при стрессе. Потребности и чистота меняются во времени. Детский режим включён изначально. Есть локальное автосохранение, экспорт/импорт JSON, дневник, продолжение жизни расчётом после закрытия, условное старение и смерть в реалистичном режиме. Добавлены сохраняемый характер, доверие, обустройство гнезда и перенос корма в тайник. Пончик по умолчанию любопытный; характер влияет на скорость и частоту выбора активностей. Общение успокаивает и повышает доверие, беспокойство во сне его снижает; между разговорами действует пауза 30 секунд. Отсутствие ребёнка не снижает доверие. Запас используется при пустой кормушке, уют гнезда улучшает восстановление энергии. Есть условные игровые недомогания после длительной грязи, нехватки пищи/воды или стресса, с причиной и подсказками ухода. Тяжесть и история рисков сохраняются. Восстановление постепенное: корм и вода должны быть доступны, потребности удовлетворены, клетка чистая, стресс низкий. Во время недомогания Пончик медленнее двигается и больше отдыхает. Это правила игры, не ветеринарная модель. Через кнопку «Предметы» доступны перестановка домика, колеса, кормушки и поилки: перетаскивание, касание нового места или стрелки. Геометрия защищает от выхода за края, пересечения с другими предметами и неподвижным мостиком. Изменения сохраняются только по «Готово», «Отмена» оставляет прежнюю планировку. Во время редактирования жизнь отображается на паузе, а по выходе прошедшее время рассчитывается. Питание, вода, гнездо, тайник и доверие от самой перестановки не меняются.

Все числовые коэффициенты — правила игры, не ветеринарные данные. Один реальный день = один игровой. Хомячок начинает с условного возраста 30 дней; после 90 игровых дней реалистичный режим включает возрастное снижение здоровья. Эта шкала не описывает настоящий срок жизни хомяка.

## Разработчику

Нужен Node.js >=20. Зависимостей нет. Проверки: `npm test`. Локальный запуск для разработчика: `python3 -m http.server 8000 --directory dist`, открыть localhost:8000. ES-модули не рассчитаны на открытие index.html через file://. Service Worker требует HTTPS или localhost.

Перед изменениями читать HANDOFF.md, TASKS.md, ARCHITECTURE.md и TESTING.md. Работу 0.1.0 пользователь подтвердил на планшете; обновлённые 0.1.1 и 0.2.x/0.3.x ещё требуют проверки.

## Расходы

Код запускается локально и не содержит платных функций или запросов. Ничего покупать для симуляции не нужно. Новые платные сервисы не подключались. Для GitHub Pages использовать публичный репозиторий; APK пока не собран. Лимиты хостинга не гарантируются кодом: при недоступности хостинга можно разместить тот же dist на GitHub Pages.
