## Verified failures and fixes

- GitHub Pages URL returned HTTP 404. Run `39261492671`, job `118090004597` failed at configure-pages: “Get Pages site failed … Not Found”. Pages must be enabled in repository Settings → Pages → Source → GitHub Actions. The connector has no Pages-settings write operation. This is an owner setting, not a JavaScript error. The workflow now publishes only `dist/` and runs simulation checks before deployment. It previously uploaded the entire repository.
- Blender run `39260394683`, job `118086209471` failed because its glTF exporter could not import NumPy. Install `python3-numpy` alongside Ubuntu Blender. A nonzero `--python-exit-code` and `if-no-files-found: error` prevent misleading green builds.
- Browser sleep energy recovery started while walking to the house. A failing regression reproduced this; recovery now requires arrival. All 105 tests pass after fixes.
- The first `main` prototype used a different storage key and inverted hunger/thirst semantics. It now migrates into the existing world schema only if no newer world is present. Original data is retained. Invalid legacy data blocks automatic overwrites.
- Godot brain reduced hunger/thirst without consuming stocks. Eating/drinking now consume actual available quantities and stop at exhaustion. Corrupt optional inventory fields are validated before any state mutation. Saving uses a temporary file and rename.
- Godot locomotion used local motion for a documented world direction. Motion/heading now use global coordinates and fixed physics updates. The GLB instance is rotated inside the locomotion root to align Blender -Y / exported +Z with Godot -Z forward.
